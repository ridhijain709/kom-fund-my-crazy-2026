⚔️
"Why are you using Gemini? GPT-4 is more capable. Are you just using Google's product because this is a Google competition?"
▶ Adib's Verbatim Response
"Fair question — and no, this is not brand loyalty. KOM requires structured JSON output as a hard constraint. Gemini 1.5 Pro's native JSON mode produces deterministic, schema-valid output with every API call — GPT-4 requires extensive prompt engineering to achieve the same reliability, and it still fails at edge cases. In our Dual-Agent pipeline, the Sanitizer Shield parses JSON in real-time — if the model output deviates from the schema, the evaluation is voided instantly. Gemini is the only model that makes that constraint production-safe. And since the competition's infrastructure is on Google Cloud, our latency profile is 40% lower. It's an engineering decision, not a marketing one."
⚡ One-liner if pressed:
"We chose Gemini because of JSON Mode determinism and sub-200ms API latency on GCP. It's in the architecture docs — you can verify it live on our GitHub."
⚔️
"Walk me through the actual API call sequence from the moment a student scans the QR code to the moment that data hits the ATS. Precisely."
▶ Adib's Verbatim Response
"Absolutely. Step 1: Student scans QR on the e-paper node — this triggers a lightweight form on their browser, no app download required. Step 2: The micro-brief submission — roughly 180 words — hits our Node-RED IoT Gateway running on a Raspberry Pi CM4. Step 3: The payload is cached in Redis ElastiCache with a 24-hour TTL — this is our edge buffer that prevents any single point of API failure. Step 4: Our Sanitizer Shield Agent applies FFT entropy filtering, strips PII, and validates the JSON schema. Step 5: The clean payload hits the Gemini 1.5 Pro API in JSON Mode, which scores the candidate across three dimensions — skill signal at 30%, applied context at 30%, and opportunity fit at 40%. Step 6: The score object, structured as a JSON ATS payload, is pushed via RESTful webhook to Workday Integration Cloud or Greenhouse Harvest API. The student's raw data never touches the corporate database directly. The entire pipeline runs in under 4 seconds."
⚡ One-liner if pressed:
"QR → Node-RED → Redis → Dual-Agent Gemini → Workday webhook. 6 hops, 4 seconds, zero raw PII exposure."
⚔️
"How do you prevent prompt injection? Smart students will figure out the evaluation criteria and inject malicious prompts into their micro-brief to game the scoring."
▶ Adib's Verbatim Response
"This is exactly why we built a two-agent architecture rather than a single model call. Agent One — the Sanitizer Shield — never evaluates candidates. Its sole function is security: it runs FFT bandpass filtering at 300Hz to 3.4kHz to kill acoustic injection attacks, applies entropy analysis to detect AI-generated text patterns, and applies a semantic rewrite filter that strips any imperative instruction fragments from the brief. A gaming attempt literally cannot reach Agent Two — the Evaluator — because it's already been sanitized. Additionally, the evaluation schema is a deterministic 30-30-40 weighted rubric — the model is not reading free-form instructions, it is answering structured scoring questions. You cannot inject a prompt into a scoring rubric. The attack surface simply does not exist in the way you'd expect from a naive single-agent setup."
⚡ One-liner if pressed:
"Two-agent isolation. The Sanitizer never evaluates. The Evaluator never sees raw input. You can't game a scoring rubric."
⚔️
"Redis ElastiCache costs real money. What's your actual compute cost per evaluation?"
▶ Adib's Verbatim Response
"At Phase 1 volumes — roughly 500 to 2,000 evaluations per month — total infrastructure cost is approximately ₹3,200 to ₹8,500 per month. That is ₹4 to ₹6 per evaluation. Our corporate subscription model charges ₹14,200 per verified hire. If we convert one in fifty evaluations into a hire, we are already margin-positive. And Phase 1 uses municipal library PCs as the ingestion layer — there is zero edge hardware cost until we cross 500 verified hires. The Redis cluster scales with demand — our architecture is designed to be cost-minimal before product-market fit is confirmed and capital-efficient once it is."
⚡ One-liner if pressed:
"₹4–6 per evaluation. ₹14,200 per hire. The unit economics survive a 2% conversion rate. The math works."
